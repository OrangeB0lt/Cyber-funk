# v1 reference screenshots

v1's screens at 360×740 (device scale 2), frozen before the cutover so they outlive `legacy/`. They're the reference for how a screen looked in v1:

- `npx tsx tools/shots.ts` captures the v2 screens of the same names and writes v1|v2 pairs to `shots/side-by-side/` (gitignored).
- 01–23 come from v1's own screenshot script (the title through the lexicon). 24–31 are the finale's screens, added in P4.
